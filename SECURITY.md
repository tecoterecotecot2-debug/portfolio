# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 4.6.x | ✅ |
| 4.5.x | ✅ |
| < 4.5 | ❌ |

## Reporting a vulnerability

Please do not open public issues for security problems. Use GitHub's private vulnerability reporting ("Security" tab → "Report a vulnerability"). We aim to respond within 72 hours.
