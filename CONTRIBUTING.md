# Contributing to Vitrine

Thanks for your interest in contributing! Vitrine is built by a community of more than 180 contributors.

## Getting set up

```bash
git clone <your-fork>
cd vitrine
npm install
npm run dev
```

## Pull requests

1. Open an issue first for anything larger than a bug fix.
2. Create a branch from `main` (`feat/…`, `fix/…`, `docs/…`).
3. Run `npm run build` before pushing; CI runs the same check.
4. Fill in the pull request template and link the related issue.
5. A maintainer from `CODEOWNERS` will review within a few days.

## Commit messages

We use [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `docs:`, `refactor:`, `perf:`, `chore:`.

## Showcase

Built something with Vitrine? Open a pull request adding your site to the Showcase table in the README.
